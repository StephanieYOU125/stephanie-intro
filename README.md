# Stephanie Universe — Personal Enterprise

A personal website that treats personal growth, research, learning, and creative work like a long-term one-person enterprise.

## Concept

Stephanie Universe is not a registered company. It is a personal operating framework:

- Time = capital
- Skills = assets
- Experiences = data
- Projects = investments
- Reflection = R&D
- Public output = products

## Website sections

- Company Profile
- Mission
- Business Units
- Core Assets
- Current Strategy
- Chinese / English / Japanese Self Introduction

## GitHub Pages

Rename or keep this file as `index.html` at the root of the repository, then enable:

**Settings → Pages → Deploy from a branch → main → / (root)**

Recommended repository name:

`stephanie-universe`

or

`stephanie-personal-enterprise`
